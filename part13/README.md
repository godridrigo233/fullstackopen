# Parte 13: Bases de datos relacionales

La solucion de los ejercicios 13.1-13.24 esta en [bloglist/](./bloglist/). Reutiliza el frontend de la Parte 5 y sustituye MongoDB por PostgreSQL/Sequelize.

- 13.1-13.4: PostgreSQL, `commands.sql`, CLI y operaciones basicas de blogs.
- 13.5-13.7: estructura del backend, likes y manejo central de errores.
- 13.8-13.12: usuarios, validacion de email, login, propiedad de blogs y asociaciones.
- 13.13-13.16: busqueda, orden y agregacion SQL de autores.
- 13.17-13.18: migraciones y validacion de year.
- 13.19-13.23: listas de lectura muchos-a-muchos, permisos y filtros.
- 13.24: sesiones revocables; logout y usuarios deshabilitados invalidan JWTs previos.

Consulta [bloglist/README.md](./bloglist/README.md) para arrancar PostgreSQL, ejecutar el CLI y correr las pruebas. La provision de Heroku del ejercicio 13.1 requiere una cuenta externa.
